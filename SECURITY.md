# Security Policy

## Project Status

Manta is in **alpha**. There are **no** stability, support, or security
guarantees at this stage — APIs, schemas, and infrastructure can change
without notice, and reported vulnerabilities are handled best-effort, not
against committed SLAs.

## Reporting a Vulnerability

Use [GitHub's "Report a vulnerability"
button](https://github.com/manta-plan/manta/security/advisories/new) under this
repository's "Security" tab — to open a private channel between you and the
maintainers.

If you're unable to use that, email <security@openenergytransition.org>.

A maintainer will acknowledge your report within 10 business days and follow up
with next steps shortly after.

Please report security bugs in third-party dependencies to the maintainers of
that dependency, not here.

## Disclosure Policy

When a report comes in, a maintainer will:

- Confirm the problem and determine affected versions.
- Audit the codebase for similar issues.
- Prepare and release a fix.

Security fixes take priority and may trigger an out-of-cycle release.

## Patching Targets

Given the project's alpha status, all severities are handled **best effort**
rather than against fixed SLAs. This will tighten as the project approaches release (ETA EOY 2026).

## End of Life

If this project stops being maintained, the repository will be archived and a
notice added stating that security updates have ceased.
