# Manta

Manta is an open-source energy modeling tool, designed to make cutting-edge
energy models (especially PyPSA) accessible to all.

More to come, soon!

## Dev Environment

### Initial Setup

```bash
uv sync
```

### Running

You can run the command locally with 

```bash
uv run main.py
```

## Technology We Use

Here's a list of some of the technology used to build Manta!

* [**Python**](https://www.python.org/) for backend development
* [**uv**](https://docs.astral.sh/uv/) for Python dependency management
