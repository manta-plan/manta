# Reference

The reference describes the Python packages and the REST API, as they are on `main`.

- [Playbook syntax](playbook/syntax.md): every key of a playbook document, and how a playbook is checked.
- [Playbook schema](playbook/schema.md): the JSON schema of a playbook document, generated from `playbook.schema.json`.
- [playbook](playbook/api.md): blocks and playbooks, generated from the docstrings.
- [runner](runner/api.md): the Prefect flows that run a playbook, generated from the docstrings.
- [REST API](backend/rest-api.md): every endpoint of the backend, generated from its OpenAPI schema.
