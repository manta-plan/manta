The run list is the operational centre of Manta. It is designed for quick scanning first, with enough detail available when a run needs attention.

## Scan the list

Each run shows the playbook, current state, start time, duration, and region. Use the state filter to focus on the work that matters right now.

Common states include:

- **Scheduled**: the run is waiting to begin.
- **Running**: the work is currently in progress.
- **Completed**: the run finished successfully.
- **Failed**: the run finished without producing a successful result.

## Open a run

Select a run to expand its details. The detail view gives you the identifiers and execution context needed to understand what happened without leaving the list.

## Refresh live work

For a running process, refresh the details and logs to retrieve the latest state. This keeps the interface useful during active operations without making the whole page feel busy.

## A good review habit

Review completed runs regularly, not only failed ones. Comparing successful runs over time helps teams see patterns in duration, output, and operating conditions.

:::caution
Treat a failed run as a signal to investigate, not as a complete explanation. The result and logs provide the context needed for the next decision.
:::
