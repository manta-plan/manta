Manta brings projects, playbooks, and runs into one place. The first workflow is intentionally small: create a project, start a run, and review its result.

## 1. Create a project

A project is the home for a piece of operational work. Give it a name that your team will recognize and add enough context for someone else to understand its purpose.

## 2. Choose a playbook

Playbooks describe repeatable work. They can represent an analysis, a forecast, a validation step, or any other process your operation needs to run consistently.

## 3. Start a run

When you start a playbook, Manta creates a run and tracks it from its initial state through completion. Each run keeps its own timing, state, and result.

## 4. Review the result

Open a completed run to inspect the result and the operational record behind it. A clear history makes it easier to compare decisions and improve the next run.

:::tip
Start with one small, repeatable workflow. A focused first playbook gives your team a useful shared reference point.
:::

## The first workflow

```text
Project -> Playbook -> Run -> Result
```
