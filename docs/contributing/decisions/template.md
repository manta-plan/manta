# ADR N: The decision, as a short statement

- **Status:** Proposed, Accepted, or Superseded by ADR N (linked), with its date
- **Decided in:** the meeting, issue, or PR where it was decided, linked

## Context

The problem and the constraints that shaped the decision, in a few sentences.

## Decision

What was decided.
If other options were considered, name each in a line, with why it was not chosen.

## Consequences

What gets easier, what gets harder, and which services change.
If the decision holds only for a stage, such as the MVP, say when to revisit it.
